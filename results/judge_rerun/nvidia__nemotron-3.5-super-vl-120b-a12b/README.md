# Every word judged again by nvidia/nemotron-3.5-super-vl-120b-a12b

21642 different (human word, predicted word) pairs from the saved answers, all judged again by **nvidia/nemotron-3.5-super-vl-120b-a12b** alone, with the same judging as before and as the paper describes it (Sec. 5): the same prompt and five categories (identical, synonym, hypernym/hyponym, semantic overlap, mismatch), human label as the reference, temperature 0, 50 words per request; **lenient = anything but a mismatch**, relations also need **temporal IoU > 0.5**. The same text after normalising counts as identical without asking, and an object Qwen left unnamed ("object 3") as a mismatch, both as before. Only the judge model differs: the paper used GPT-4o-mini (prompt not released); the earlier tables used Kimi K3, and Claude for the words Kimi K3 never judged. Made by `tools/rejudge.py`; verdicts in `results/traser_bench/judge_cache_nvidia__nemotron-3.5-super-vl-120b-a12b.json`.
